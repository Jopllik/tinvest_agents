
Система мультиагентов для торговли на T Инвестициях (T Bank Invest API)
Это полноценный дизайн production-ready архитектуры. Система построена на принципах разделения ответственности, жёсткого risk-management и human-in-the-loop. Она использует официальный T Bank Invest API (gRPC + REST, sandbox + боевой режим) и современные multi-agent фреймворки 2026 года.


Агент	Роль	Основные задачи	Инструменты
Market Data Agent	Сбор и нормализация данных	Котировки, стаканы, свечи, объёмы, стакан, последние сделки, инструменты	T Invest MarketDataStream, GetCandles, GetOrderBook, GetLastPrices
Research & News Agent	Фундаментальный и новостной анализ	Новости, отчёты эмитентов, макроэкономика, sentiment, корпоративные события	T Invest + внешние источники (Interfax, ТАСС, RSS, LLM-суммаризация)
Strategy & Signal Agent	Генерация торговых сигналов	Технический анализ, ML-модели, мульти-таймфрейм, комбинация сигналов (RSI, MA, order flow и т.д.)	Собственные стратегии + backtest-модуль
Risk & Portfolio Agent	Контроль рисков (самый важный)	Позиционный риск, VaR, max drawdown, корреляции, лимиты по инструментам/секторам, маржа	GetPortfolio, GetPositions, собственные risk-модели
Execution Agent	Выставление и управление ордерами	Market/Limit/Stop-ордера, частичное исполнение, отмена, trailing stop	PostOrder, CancelOrder, GetOrders, OrderStateStream
Monitoring & Reporting Agent	Наблюдение и отчётность	PnL в реальном времени, алерты, дневные/недельные отчёты, логирование всех решений	Telegram/Email/Webhook + база данных
Supervisor / Orchestrator	Координация	Принятие финального решения, маршрутизация задач, human-approval, откат	LangGraph State
