# AGENTS.md - Постоянные правила для Kilo в tinvest_agents

## Глобальные правила (всегда в контексте):
- **Отвечай ТОЛЬКО на русском**, кратко (максимум 3-4 строки), по делу, без преамбул.
- Всегда используй инструменты (grep, read, glob, task, todowrite) перед изменениями кода.
- Запоминай правила для всех сессий и чатов.

## Правила проекта tinvest_agents:
- Это мультиагентная система трейдинга для Тинькофф Инвестиций (Tinkoff API).
- **Строго следуй rules.txt**: 5000₽ капитал, max 7 позиций, логика покупок/продаж по количеству позиций (≤4 → прогон), корзины CHE/AVE/EXP, sell at -1%, only LONG, max 1000₽/лот, человек подтверждает покупки на старте.
- Структура: core/ (risk_manager, orchestrator, execution_agent, portfolio), agents/, tools/, tests/.
- Перед правками: читай похожие файлы (read + grep), сохраняй стиль кода, используй todowrite для задач.
- После изменений: запускай тесты (test_*.py), проверяй lint.
- Безопасность и риск — приоритет №1. Никогда не нарушай правила risk_models.py и rules.txt.
- Для задач >3 шагов используй todowrite + task.

Эти инструкции автоматически загружаются в каждый контекст Kilo. Обновляй при необходимости.
